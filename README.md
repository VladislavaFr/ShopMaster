# ShopMaster

Учебный проект интернет-магазина на Django.

## Описание

Проект создан для выполнения домашек курса Django.  
Состоит из одного приложения `catalog`, с главной страницей и страницей контактов.  

## Структура проекта

- `config/` — настройки Django проекта
- `catalog/` — основное приложение
- `templates/catalog/` — HTML-шаблоны
- `static/catalog/` — статика (CSS, JS)
- `db.sqlite3` — база данных SQLite

## Как запустить

1. Клонировать репозиторий
2. Создать и активировать виртуальное окружение
3. Установить зависимости: `pip install -r requirements.txt`
4. Выполнить миграции: `python manage.py migrate`
5. Запустить сервер: `python manage.py runserver`
6. Открыть в браузере: `http://127.0.0.1:8000/`
